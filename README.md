## 重要公告（2026-11-26）

2.1.6 起更换了签名证书，App 内自动更新会提示「签名冲突 / 安装失败」。

升级方式：

1. 用浏览器打开下载页
2. 下载最新版 APK
3. **卸载手机上的旧版本**
4. 安装刚下载的新版本

卸载不影响云端激活记录（`activations.json` 保留），重新填写邀请码即可；本地登录态和本地题库会清空，重新登录一次即可。

从 2.1.6 起签名固定，后续版本恢复正常 App 内自动更新。
